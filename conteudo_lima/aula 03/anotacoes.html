Principais categorias no HTML5

Metadata Content Flow Content Sectioning Content Heading Content Phrasing Content Embedded Content Interactive Content

Metadata Content

<title> Informa o título

<meta> Definir codificação

<link> e <style> importar CSS

<script> configurar o computador da página (Javascripit)

Flow Content

Representa a maior parte dos elementos usados no body

<div> Caixa de divisão genérica, serve para agrupar "pedaços" de código

<p> Para colocar blocos de texto comuns na minha página

<section> Agrupa conteúdos que partilham do mesmo assunto ou ideia

<article> Conteúdo independente e completo por si só (faz sentido sozinho)

<img> Mostra uma imagem, foto, desenho, etc. (não precisa de tag de fechamento)

<form> criar formulários, o usuário poderá digitar dados, enviar mensagem ou fazer login.

Sectioning Content

Organizar grandes áreas do documento

<section> Agrupa conteúdos que partilham do mesmo assunto ou ideia

<article> Conteúdo independente e completo por si só (faz sentido sozinho)

<aside> Serve para guardar um conteúdo secundário/lateral (links relacionados, anúncios, biografia, etc.)

<nav> Agrupa links de navegação

Heading Content

h1, h2, h3, h4, h5, h6 -> Para adicionar títulos e subtítulos

<hgroup> Serve para agrupar elementos de título, exemplo:

"Aprenda HMTML

Senai Americana"

Phrasing Content

Elementos que marcam textos ou partes de texto

<span> Um bloco genérico, não muda nada sozinho. Serve para agrupar pedaços de txto e aplicar CSS ou funções com javascript.

<a> Cria um link para direcionar o usuário para outra página, utilizando o atributo href. Exemplo: Clique aqui para ir ao site do bitcoin

<strong> Deixar uma parte do texto em negrito

<em> Deixar uma parte do texto em itálico

<mark> Adiciona um marcador em um aparte do texto

<img> Mostra uma imagem, foto, desenho, etc. (não precisa de tag de fechamento)

Embedded Content

<img> Mostra uma imagem, foto, desenho, etc. (não precisa de tag de fechamento)

<video> Adiconar um videio direto no site (pode mostrar botões de play e pause)

<canvas> Criar uma tela em branco que poderá ser usada pelo javascript

<svg> Desenha gráficos baseados em vetores

<iframe> Coloca outra página inteira dentro do seu website (muito usado paraa dicionar mapas e videos de outras paginas)

Interactive Content

<a> Cria um link para direcionar o usuário para outra página, utilizando o atributo href.

<button> Criar um botão clicavel. Exemplo:

<input> Usado para receber dados. Dentre os dados aceitos estão:
type="text": campo de texto curto.
type="password": oculta os caracteres digitados
type="email" ou type="number":valida dados específicos
type="checkbox" ou type= "radio": caixas de marcação e escolha única.
type é uma tag que não precisa de fechamento

<select>Cria uma caixa de seleção em formato de lista suspensa(dropdown)

<textarea>Cria uma "caixa" com várias linhas, serve para textos longos, comentários, mensagens
